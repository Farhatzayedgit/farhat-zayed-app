# أبليكيشن فرحات زايد

التطبيق الرسمي لأغاني فرحات زايد — اسمع الأغاني صوت بس، شوف الكليبات من قناة يوتيوب، واحفظ الأغاني أوفلاين أو حمّلها MP3.

**اللينك:** https://farhatzayedgit.github.io/farhat-zayed-app/

## إضافة أغنية جديدة
1. حط ملف الصوت في `audio/` باسم الرقم الجاي (مثلاً `s71.mp3`).
2. حط الصورة المصغرة في `covers/` بنفس الرقم (`s71.jpg`، مقاس 640×360).
3. ضيف سطر في أول `songs.js`:
   `{"id": "s71", "t": "اسم الأغنية", "f": "", "yt": "كود فيديو يوتيوب", "d": المدة بالثواني},`
   (`f` = اسم المشارك لو دويتو، زي `"روح"`).
